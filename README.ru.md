# Exomyth

Приватная вики для писателей и создателей миров, которая работает без интернета. Ваш мир — это
папка с обычными Markdown-файлами на вашем устройстве. Без аккаунта, без сервера, без слежки.

> **Статус: ранняя альфа (v0.8).** Страницы, типизированные связи, стабильная панель связей, граф
> связей со стабильной раскладкой, карточки, хроника, интерактивные карты с метками, перемещение по
> годам, картинки, видео и аудио, счётчик слов, быстрые заметки, копии в .zip, предпросмотр страниц
> при наведении, поиск, теги, переименование с обновлением ссылок. [English version](README.md)

## Принципы

- **Приватность по построению.** Приложение не делает сетевых запросов (страница поставляется с
  политикой безопасности, которая их запрещает). Миры лежат в выбранной вами папке или в хранилище
  самого браузера.
- **Ваши файлы, ваш формат.** Каждая страница — файл `.md` с небольшой YAML-шапкой. Папку можно
  открыть в любом редакторе, синхронизировать чем угодно или положить в Git. Если Exomyth исчезнет,
  ничего не потеряется.
- **Стабильные связи, в которых не заблудиться.** Связи показаны в фиксированной панели рядом со
  страницей и всегда в одном порядке: по типу связи, затем по алфавиту. Граф связей держит каждую
  страницу на своём месте: позиции сохраняются в мире, новые страницы встают рядом с соседями, и
  ничего не перестраивается, пока вы сами не попросите.
- **Открытый код.** AGPL-3.0: пользоваться и изменять можно свободно, а производные работы, включая
  онлайн-сервисы, обязаны оставаться открытыми под той же лицензией. См. [LICENSE-NOTE.md](LICENSE-NOTE.md).

## Как попробовать

**Открыть приложение: https://exonerv-pec.github.io/Exomyth/** — ничего устанавливать не нужно. Сайт
только доставляет приложение в браузер, а ваши миры остаются на вашем устройстве.

### Запустить у себя

Пошаговая инструкция: [BUILDING.ru.md](BUILDING.ru.md). Коротко, если стоит Node.js 20+:

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # тесты ядра и интерфейса
npm run build      # статический сайт в dist/
```

Откройте приложение в **Chrome, Edge или Opera**, чтобы работать прямо с папкой на компьютере. В
других браузерах миры хранятся в самом браузере.

Небольшой пример мира лежит в [`examples/demo-world/`](examples/demo-world/): откройте эту папку в
приложении или нажмите «Открыть демо-мир» на стартовом экране, чтобы получить копию в браузере.
Файлы — обычный Markdown, так что по ним заодно видно, как устроен формат.

## Формат файлов

Страница — Markdown-файл. Необязательная YAML-шапка в начале хранит метаданные и типизированные связи:

```markdown
---
aliases: [Кира, Серебряная Кира]
tags: [персонаж, герой]
дата рождения: 412
relations:
  отец: "[[Арн Вейл]]"
  союзник: ["[[Бо Тарн]]", "[[Орден Серебряной Реки]]"]
  место рождения: "[[Ривертаун]]"
pinned: ["[[Арн Вейл]]"]
---
# Кира Вейл

Дочь [[Арн Вейл|короля Арна]]. Выросла в [[Ривертаун]].

Тайна: ||Эва Кроу — её сводная сестра||.
```

| Элемент | Значение |
| --- | --- |
| `[[Страница]]`, `[[Страница\|текст]]`, `[[Страница#Заголовок]]` | Ссылка на страницу (по имени, псевдониму или части пути), с текстом или заголовком |
| `relations:` | Типизированные связи: ключ — тип связи, значение — ссылка или список ссылок |
| `aliases:` | Другие имена, по которым можно ссылаться |
| `image:` | Картинка страницы (портрет, герб, карта): видна в инфобоксе и на карточке |
| `map:`, `pins:` | Превращает страницу в интерактивную карту с метками (см. «Карты» ниже) |
| `from:`/`to:`, `born:`/`died:`, `founded:`, `year:` | Годы страницы для хроники и показа по годам (см. «Хроника» ниже) |
| `tags:` и `#тег` | Теги (в шапке или в тексте) |
| `pinned:` | Ссылки, которые стоят первыми в своей группе на панели связей |
| `\|\|секрет\|\|` | Спойлер: скрыт в режиме чтения до клика |
| `![[карта.png]]`, `![[карта.png\|400]]`, `![[вступление.mp4]]`, `![[тема.mp3]]` | Картинка, видео или звук из мира (можно указать ширину или подпись после `\|`) |
| остальные поля шапки | Показываются фактами в инфобоксе страницы |

Настройки мира хранятся в `.exomyth/settings.json`:

```json
{
  "relationTypes": [
    { "id": "отец", "inverse": "дети" },
    { "id": "союзник", "symmetric": true }
  ]
}
```

`relationTypes` задаёт порядок групп на панели, подпись для обратной стороны связи (`inverse`) и то,
одинакова ли связь с обеих сторон (`symmetric`). Удалённые страницы уходят в `.trash/` внутри мира и
никогда не стираются насовсем.

Позиции на графе хранятся в `.exomyth/graph.json` (`[x, y, наПолке]` для каждой страницы и
закреплённый цвет для каждой папки). Удалите файл, чтобы разложить граф с нуля, или нажмите
«Разложить заново» на графе.

## Граф связей

Переключитесь на **Граф** в верхней панели (или нажмите кнопку графа на панели связей).

- Каждая страница — кружок цвета своей папки верхнего уровня. Линии соединяют связанные страницы:
  темнее — типизированные связи, светлее — простые упоминания.
- Страницы совсем без связей лежат на «полке» под графом и нарисованы полыми кружками.
- Клик выбирает страницу (панель связей переключается на неё), двойной клик открывает, перетаскивание
  передвигает.
- Наведите на страницу, чтобы подсветить её соседей и увидеть названия связей.
- «Соседи» и «Соседи соседей» показывают только окрестность выбранной страницы; позиции при этом не
  меняются, так что карта не «уезжает».

## Карты

Любая страница становится картой, если в шапке указать картинку: `map: карта.png`. В режиме чтения
появится интерактивная карта: приближение колесом или щипком, перемещение перетаскиванием, кнопка
«Во весь экран».

- **Метки** ведут на страницы (город, крепость, персонаж) или просто подписаны. Наведите на метку —
  появится превью страницы, кликните — страница откроется. Метки окрашены в цвет папки своей страницы.
- **«Редактировать метки»**: клик по карте ставит метку, метки можно перетаскивать, у выбранной метки
  задаются страница, подпись и годы. Стрелки двигают выбранную метку, Delete удаляет.
- **Годы**: у метки могут быть `from` и `to` (включительно). Включите «Показывать по годам» и двигайте
  ползунок — карта покажет мир таким, каким он был в этом году.

Метки хранятся в шапке страницы обычным текстом; координаты — доли картинки, поэтому не съезжают, если
заменить картинку на более крупную:

```yaml
map: silver coast.svg
pins:
  - page: "[[Rivertown]]"
    x: 0.52
    y: 0.62
    from: 300
  - label: Old Watchtower
    x: 0.3
    y: 0.27
    from: 210
    to: 405
```

Страницы на метках считаются ссылками: они видны в обратных ссылках и на графе.

## Карточки

Переключитесь на **Карточки** в верхней панели, чтобы смотреть мир карточками.

- **Вкладки папок** («Персонажи», «Места», «Организации»...) показывают все страницы папки карточками:
  с картинкой или монограммой, цветом папки и главными фактами.
- **Досье страницы** показывает выбранную страницу большой карточкой, а под ней все связанные
  страницы, сгруппированные по типу связи: у организации — руководитель, члены, союзники и те, кто её
  упоминает. Группы и карточки идут в том же неизменном порядке, что и на панели связей.
- Клик по карточке открывает её досье, двойной клик — саму страницу.

## Хроника

Переключитесь на **Хронику** в верхней панели, чтобы увидеть, кто когда жил и что когда случилось.
У каждой страницы с годами своя строка, строки сгруппированы по папкам: полоса от первого года до
последнего, ромбик для события в один год и полоса, которая тает, если всё ещё продолжается
(персонаж жив, город стоит).

Годы можно указать в полях **«Годы»** вверху панели связей или вписать в шапку страницы словами,
которые ей подходят:

```yaml
born: 412          # или from:, founded:, built:, родился:, основан:
died: 455          # или to:, destroyed:, dissolved:, умер:, разрушен:
year: 430          # событие в один год
years: 429-430     # событие на несколько лет
```

Считаются только целые годы (`412`, `412 AE`, `-50`). Клик по строке выбирает страницу, двойной клик
открывает её; `Ctrl` + колесо меняет масштаб.

**Перемещение по годам.** Нажмите на шкалу лет и ведите или включите **«Показывать по годам»** и
двигайте ползунок. Выбранный год общий для всего мира: на хронике его отмечает линия, граф и карточки
приглушают страницы, которых в этом году ещё (или уже) нет, а карты прячут метки. Метка без своих
годов следует годам своей страницы. Страницы без годов видны всегда.

## Помощь в работе над текстом

- **Счётчик слов.** В верхней панели видно, сколько слов на открытой странице; если навести на
  число, покажется счёт для всего мира. Считается только текст, который видит читатель: у ссылок
  их видимый текст, а шапка страницы и файлы не считаются.
- **Режим без отвлечений.** **Ctrl+.** (или кнопка с уголками в верхней панели) прячет всё, кроме
  текста, который вы пишете; в углу остаётся счётчик слов. **Esc** возвращает всё обратно.
- **Проверка орфографии.** Редактор использует встроенную проверку браузера: она работает без
  интернета на языках, настроенных в браузере. Кнопка **ABC** в верхней панели её выключает, например
  когда на странице много вымышленных имён.
- **Быстрые заметки.** Нажмите **Alt+I** где угодно (или кнопку с лампочкой вверху боковой панели),
  чтобы записать идею, не уходя со страницы. Она добавится с датой и временем на страницу **«Идеи»**,
  которая создастся при первой заметке.

## Папки

Страницы лежат в папках («Персонажи», «Места»…). Чтобы перенести страницу, перетащите её на папку в
боковой панели (или на название мира, чтобы положить в корень) либо нажмите кнопку с папкой рядом со
страницей. Ссылки по имени продолжают работать, а ссылки с путём к папке обновляются.

## Горячие клавиши

Нажмите **Ctrl+/** (или **?** вне текстового поля) либо кнопку с клавиатурой внизу боковой панели,
чтобы увидеть список всех клавиш. Самые полезные: **Ctrl+K** — поиск, **Alt+I** — быстрая заметка,
**Ctrl+клик** по `[[ссылке]]` в редакторе — перейти по ней. На Mac вместо Ctrl — ⌘, вместо Alt — ⌥.

## Резервные копии: мир в .zip

Кнопка со стрелкой вверху боковой панели скачивает весь мир (страницы, настройки, картинки, звуки)
одним .zip-файлом. Внутри обычная папка мира: её можно распаковать и открыть как папку или снова
открыть кнопкой **«Открыть мир из .zip»** на стартовом экране, и мир появится в браузере как новый.
Ничего никуда не загружается: файл собирается на вашем устройстве.

Миры, которые хранятся в браузере, браузер может стереть, когда на диске почти нет места. Exomyth
просит браузер их сохранять, но надёжнее время от времени скачивать .zip.

## Картинки, видео и аудио

Перетащите файлы в редактор, вставьте скриншот из буфера или нажмите кнопку с картинкой в верхней
панели. Файлы сохраняются в папку `attachments/` внутри мира и вставляются как `![[имя файла]]`.
Поддерживаются PNG, JPEG, GIF, WebP, AVIF, SVG, BMP; MP4, WebM, OGV, MOV; MP3, WAV, OGG, Opus, M4A, AAC,
FLAC. Всё воспроизводится из вашего собственного хранилища; картинки по веб-адресам показываются
ссылками и сами не загружаются. В режиме **«Текст»** картинки и плееры видны прямо под строками, где они
вставлены; в режиме **«Рядом»** — в правой половине, где текст для чтения.

## Предпросмотр страниц

Наведите курсор или фокус на ссылку (в режиме чтения, в редакторе, на панели связей или на графе) —
появится карточка с названием, папкой, псевдонимами, несколькими фактами, началом текста и числом
связей. Для `[[Страница#Раздел]]` показывается этот раздел. На графе карточка появляется в правом верхнем углу
и не закрывает связи страницы, на которую вы навели.

## Устройство проекта

```
src/core/       Чистый TypeScript без интерфейса: разбор файлов, индекс ссылок, модель панели
                связей, модель графа и стабильная раскладка, предпросмотр страниц,
                хранилища (папка / браузер / память), операции с миром
src/components  Интерфейс на Svelte 5
tests/          Vitest: логика ядра и отрисованный интерфейс (jsdom)
```

Панель связей — чистая функция от страниц мира (`VaultIndex.panel`): именно это гарантирует стабильный
порядок. Тест в `tests/core.test.ts` проверяет, что перемешивание порядка загрузки ничего не меняет.
