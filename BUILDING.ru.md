# Сборка Exomyth

[English version](BUILDING.md)

Эта инструкция для тех, кто хочет запустить Exomyth из исходного кода, что-то в нём поменять или
опубликовать свою копию. Чтобы просто пользоваться приложением, откройте
**https://exonerv-pec.github.io/Exomyth/** — устанавливать ничего не нужно.

## Что понадобится

- **Node.js 20 или новее** (лучше 22): <https://nodejs.org>. В комплекте идёт `npm`.
- **Git**, чтобы скачать код: <https://git-scm.com>. (Или на GitHub нажмите «Code → Download ZIP».)
- Свежий **Chrome, Edge или Opera**, чтобы работать с мирами в папках. Firefox и Safari тоже подойдут,
  но там миры хранятся только в браузере.

Проверьте версии в терминале:

```bash
node --version   # v20 или выше
npm --version
```

## 1. Скачайте код

```bash
git clone https://github.com/Exonerv-Pec/Exomyth.git
cd Exomyth
```

## 2. Установите зависимости

```bash
npm install
```

Команда скачает библиотеки из `package.json` в папку `node_modules/` (около 100 МБ). Это нужно сделать
один раз и потом повторять, только если изменится `package.json`.

## 3. Запустите приложение для разработки

```bash
npm run dev
```

Откройте адрес, который появится в терминале, обычно <http://localhost:5173>. Страница сама
обновляется, когда вы меняете файлы. Остановить сервер: `Ctrl+C`.

## 4. Проверьте изменения

```bash
npm run check   # проверка типов и Svelte
npm test        # автоматические тесты
```

Обе команды должны проходить без ошибок. Публикация на GitHub тоже их запускает и останавливается,
если что-то не прошло.

## 5. Соберите готовое приложение

```bash
npm run build
```

Готовое к размещению приложение появится в папке `dist/`. Посмотреть его у себя:

```bash
npm run preview   # открывает dist/ по адресу http://localhost:4173
```

Если открыть `dist/index.html` двойным кликом прямо с диска, приложение **не запустится**: браузеры не
выполняют его скрипты с адресов `file://`. Используйте `npm run preview` или любой веб-сервер.

Есть и сборка в один файл, она нужна для превью:

```bash
npm run build:single   # создаёт dist-single/index.html, где всё внутри одного файла
```

## 6. Публикация через GitHub Pages

Репозиторий публикует себя сам. Сценарий `.github/workflows/pages.yml` запускается при каждом коммите
в ветку `main`:

1. ставит зависимости (`npm ci`),
2. запускает `npm run check` и `npm test`,
3. собирает приложение (`npm run build`),
4. выкладывает папку `dist/` на GitHub Pages.

Сайт только доставляет приложение в браузер. Миры остаются на устройстве каждого человека:
приложение ничего никуда не отправляет, а его политика безопасности (CSP) блокирует сетевые запросы.

GitHub Pages и GitHub Actions бесплатны для публичных репозиториев на обычных серверах GitHub.

### Своя копия (форк)

1. На GitHub в репозитории Exomyth нажмите **Fork**.
2. В своём форке: **Settings → Pages → Source: GitHub Actions**.
3. Сделайте коммит в `main` (или откройте **Actions → Deploy to GitHub Pages → Run workflow**).
4. Через несколько минут приложение будет по адресу `https://<ваш-ник>.github.io/Exomyth/`.

На форк действует та же лицензия AGPL-3.0: если вы публикуете изменённую версию, её код тоже должен
быть открытым. Подробнее: [LICENSE-NOTE.md](LICENSE-NOTE.md).

## Если что-то не работает

| Проблема | Что делать |
| --- | --- |
| `npm install` падает или `npm run dev` пишет об ошибках синтаксиса | Слишком старый Node.js. Поставьте версию 20 или новее. |
| Публикация долго висит в статусе «Queued» | Откройте **Actions**, отмените запуск и нажмите **Re-run all jobs**. Проверьте, что в **Settings → Pages → Source** выбрано **GitHub Actions**. |
| Публикация падает с ошибкой Pages | В **Settings → Environments → github-pages** разрешите публикацию из ветки `main`. |
| Пустая страница, если открыть `dist/index.html` с диска | Так и должно быть, используйте `npm run preview` (шаг 5). |
| Нет кнопки «Открыть папку с миром» | Браузер не умеет открывать папки (Firefox, Safari) или приложение открыто внутри другой страницы. Откройте приложение напрямую в Chrome, Edge или Opera. |
| Тесты падают после правки демо-мира | `tests/demo.test.ts` проверяет, что в демо нет битых ссылок. Исправьте ссылку или добавьте страницу. |

## Где что лежит

```
src/core/         логика без интерфейса: разбор файлов, ссылки, панель связей, раскладка графа,
                  предпросмотр, медиафайлы, хранилища, операции с миром
src/components/   интерфейс (Svelte 5)
src/i18n.ts       тексты интерфейса на русском и английском
examples/         демо-мир, который встроен в приложение
tests/            автоматические тесты (Vitest)
.github/          сценарий публикации на GitHub Pages
```
