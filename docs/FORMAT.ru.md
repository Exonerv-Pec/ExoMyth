# Формат файлов Exomyth

Версия 1. [English version](FORMAT.md)

Мир — это папка. Всё в ней — обычные файлы, которые прочтёт любой редактор: страницы Markdown с
YAML-шапкой, обычные картинки и звуки и несколько маленьких JSON-файлов, которые Exomyth хранит для
себя. Здесь перечислено всё, что Exomyth читает и пишет, чтобы мир можно было создавать, менять и
читать другими программами и вручную.

## Что обещает 1.0

Начиная с версии 1.0, во всех версиях 1.x:

- **Мир продолжает работать.** Каждая страница, поле шапки и файл, описанные здесь, значат одно и
  то же во всех следующих версиях 1.x. Ничего не переименовывается, не меняет смысл и не пропадает.
- **Новое добавляется, а не подменяет старое.** Новая возможность получает новые поля шапки или новые
  файлы. Страницы, которые ею не пользуются, не трогаются.
- **Правки остаются маленькими.** Меняя шапку, Exomyth меняет только нужное поле и сохраняет
  остальные поля, их порядок и ваши комментарии. Он никогда не переписывает страницу, которую его не
  просили менять.
- **Миры из 0.x открываются** как есть, в том числе сохранённые под прежним названием проекта
  (`.mythloom/`).
- **Ничего не стирается.** Удалённые страницы уходят в `.trash/` внутри мира, версии хранятся в
  `.exomyth/versions/`.

Изменение, которое нарушило бы что-то из этого, потребовало бы Exomyth 2.0, и в заметках к нему было
бы сказано, как перенести мир.

## Папка

```
Мой мир/
  Добро пожаловать.md           страницы — в любых папках
  Персонажи/Кира Вейл.md
  attachments/rivertown.png     картинки, видео и звук (новые файлы кладутся сюда)
  Шаблоны/Персонаж.md           свои шаблоны страниц (или Templates/)
  .exomyth/settings.json        типы связей мира
  .exomyth/graph.json           где стоят страницы на графе
  .exomyth/writing.json         слова и время по дням
  .exomyth/versions/…           сохранённые версии страниц
  .trash/…                      удалённые страницы
```

Страницы — это все файлы `.md` вне `.exomyth/`. Папки `.git`, `.trash`, `.obsidian` и
`node_modules` никогда не читаются как часть мира.

## Страницы

Страница — файл `.md` в UTF-8. Её название — имя файла без `.md`. Необязательная шапка между строками
`---` в самом начале записана на YAML.

### Ссылки и пометки в тексте

| Как написать | Что это |
| --- | --- |
| `[[Страница]]`, `[[Страница\|текст]]`, `[[Страница#Заголовок]]` | Ссылка по названию, другому имени или концу пути; с подписью или заголовком |
| `![[файл.png]]`, `![[файл.png\|400]]`, `![[файл.png\|Подпись]]` | Картинка, видео или звук мира; ширина или подпись |
| `![[Страница]]` | Ссылка на страницу, показанная как ссылка |
| `#тег` | Тег |
| `\|\|слова\|\|` | Спойлер, скрыт до нажатия |
| `{==слова==}{>>комментарий<<}`, `{>>комментарий<<}` | Комментарий к словам или в одном месте (CriticMarkup) |
| `{>>комментарий<<}{>>ответ<<}` | Комментарии сразу за комментарием — ответы на него |
| `{++добавлено++}`, `{--убрано--}`, `{~~было~>стало~~}` | Предложенные правки |

Ссылка находит страницу с таким названием, а если её нет — страницу с таким другим именем; ссылка со
`/` находит страницу, путь которой так заканчивается. Регистр букв не важен, а когда у двух страниц
одно название, побеждает та, что лежит менее глубоко. Внутри кода ссылки не работают.

### Поля шапки

| Поле | Значение | Что это |
| --- | --- | --- |
| `title` | текст | Заголовок страницы, если он не совпадает с именем файла |
| `aliases` | список | Другие имена для ссылок |
| `tags` | список | Теги (вместе с `#тег` в тексте) |
| `relations` | тип → ссылка или список ссылок | Связи с типом: `отец: "[[Арн Вейл]]"` |
| `pinned` | список ссылок | Связи, которые идут первыми в своей группе |
| `image` | файл | Картинка страницы в инфобоксе и на карточке |
| `born`, `died`, `founded`, `from`, `to`, `year`, `years`, `родился`, `год` и подобные | год или дата | Когда жил или происходил предмет страницы (см. «Даты») |
| `map` | файл | Делает страницу картой этой картинки |
| `pins`, `regions` | список | Метки и области на карте (см. «Карты») |
| `manuscript: true` | | Делает страницу книгой (см. «Книги») |
| `status`, `pov`, `summary` | текст | Готовность сцены (`idea`, `draft`, `revised`, `done` или по-русски), чьими глазами, краткое содержание |
| `playlist: true` | | Делает страницу плейлистом аудиофайлов из её списка |
| `moodboard: true`, `board` | список | Делает страницу мудбордом (см. «Мудборды») |
| `calendar: true`, `months`, `week`, `eras` | | Делает страницу календарём мира (см. «Даты») |
| `revision` | список текста | Что исправить; `[x]` перед сделанным |
| `template` | словарь | Только в шаблонах: `folder:` говорит, куда класть новые страницы; не копируется |
| всё остальное | текст, число, список | Факт, показывается в инфобоксе страницы |

`true` можно писать и как `yes` или `да`.

### Даты

Начало берётся из `from`, `born`, `founded`, `built`, `established`, `formed`, `began`, `start`,
`родился`, `основан` и подобных, конец — из `to`, `died`, `dissolved`, `destroyed`, `fell`,
`abandoned`, `ended`, `end`, `умер`, `разрушен` и подобных, а одна точка или промежуток — из `year`,
`years`, `год`, `годы`. Значение — год (`412`, `-50`) или дата: `3 Frostmonth 412`, `Frostmonth 412`,
`412-01-03`, `412 AR`, `5 марта 412`, `Year 112 of the Second Age` и промежутки вроде
`28 Leaffall 429 – Thaw 430`.

Календарь мира — его первая страница с `calendar: true`:

```yaml
calendar: true
months:
  - Морозень: 30          # месяц и его дни
  - name: Оттепель
    days: 28
  - Посевная              # 30 дней, если не сказано
week: [Лунник, Приливник, Каменник, Огневик, Отдых]
eras:
  - name: Эпоха Реки
    short: ЭР
    start: 1              # год от начала времён, который стал первым годом эпохи
```

Без такой страницы годы делятся на двенадцать обычных месяцев.

### Карты

```yaml
map: silver coast.svg
pins:
  - page: "[[Ривертаун]]"     # или label: Старая башня
    x: 0.42                    # доли картинки: 0 — левый или верхний край, 1 — правый или нижний
    y: 0.63
    from: 300                  # годы, когда место было (необязательно)
    to: 450
    layer: Политика            # необязательно
regions:
  - page: "[[Земли Ордена]]"
    color: "#a86214"
    points: [[0.1, 0.2], [0.4, 0.2], [0.3, 0.5]]
```

### Книги

Страница с `manuscript: true` — книга. Её заголовки `##` — главы, а ссылки в пунктах списков под
ними — сцены, по порядку:

```markdown
## Глава 1. Река
- [[Прибытие в Ривертаун]]
- [[Рынок]]
```

Всё остальное на странице книги сохраняется в точности как написано.

### Мудборды

```yaml
moodboard: true
board:
  - image: storm coast.jpg     # x, y, w (и h) — в ширинах доски
    caption: С чего всё начинается
    x: 0.05
    y: 0.04
    w: 0.4
  - color: "#a86214"
  - quote: Море хранит то, что ему отдали.
    source: Старая поговорка
  - page: "[[Ривертаун]]"
  - note: Мокрый камень, чайки.
    tint: "#f3e3a1"
```

### Плейлисты

Страница с `playlist: true` играет по порядку аудиофайлы из пунктов своего списка:
`- ![[Fiddle in the rain.mp3]]`, `- ![[Last call.ogg|Last call, slow]]`.

## Файлы приложения

`.exomyth/settings.json` — типы связей мира в том порядке, в каком их показывает панель.

```json
{ "relationTypes": [ { "id": "отец", "inverse": "дети" }, { "id": "союзник", "symmetric": true } ] }
```

Для семейных деревьев тип может сказать `"family": "parent" | "child" | "spouse" | "sibling" | "none"`.

`.exomyth/graph.json` — где стоит каждая страница на графе. Если его удалить, граф просто разложится
заново.

`.exomyth/writing.json` — добавленные слова и секунды письма по дням и цель на день.

`.exomyth/versions/<путь страницы>/<дата> <время>[ <название>].md` — сохранённые версии страницы,
каждая — полная копия страницы, какой она была.

`.trash/<путь страницы>` — удалённые страницы.

## Шаблоны

Страницы в `Шаблоны/` (или `Templates/`) в корне мира — шаблоны, а не часть мира: для новой страницы
в них подставляются `{{title}}` и `{{date}}`.
